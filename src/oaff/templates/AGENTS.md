# AFF Findings in this repository

For tasks that may use or produce a reusable conclusion, read `aff/policy.md`.
Before a related run or decision, browse `aff/index.md`, inspect applicable
`.aff` packages, and check their stated conditions and exclusions. Verify
cited source bytes when available. Say which Findings informed the work and
which were out of scope or could not be checked.

After a run, propose a Finding only when there is a specific, reusable
conclusion supported by a source record. Follow `aff/policy.md` before using
`aff capture`; preserve the original note or run record. A valid digest or
foreign receipt does not establish truth, producer identity, or permission to
rely on a Finding. You may propose and run mechanical checks; only the team's
authorized decision path may admit, reject, or act on withdrawal locally.
Never turn an imported Finding into local approval.
